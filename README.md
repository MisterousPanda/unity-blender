# Direct the tools

One page for learning to direct Unity, Blender, and Grok, then supervise the tool calls.

Unity runs the interactive scene. Blender makes the editable model. Grok is where creations and additions start. Dreamina, Higgsfield, and world models are the studios and file types the notes name. Progress stays in this browser. The page does not call those tools.

```bash
npm install
npm test
npm run dev
```
